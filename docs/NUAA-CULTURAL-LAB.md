# 南航灵感参数化文创工作台

在铸想创作页面展开「南航灵感 · 参数化文创工作台」。选择模板和主题，调整尺寸、镂空开关、额外孔径与位置；可上传白底黑色或透明底黑色图案，将其转换成实体凹刻。点击生成后可旋转预览、下载 STL；勾选批量时下载包含三款 STL 与参数记录的 ZIP。

结构风格可选「翼肋流线」「穹顶拱券」和「简洁条孔」。笔筒的前两款使用渐变筒身和不同形状的镂空；水上飞机主题的翼肋风格增加四片一体式翼肋，太庙井主题增加井栏式环形边框。书签有翼形外轮廓，尺子在刻度外侧增加镂空窗。可调笔筒壁厚、镂空列数与图案大小。实际模型最大包围尺寸可能大于笔筒直径参数，页面会显示实际尺寸。当前产品是预设参数化结构，不是基于载荷求解的拓扑优化。

生成后使用「实际模型静态预览」及左右旋转按钮。该图由本次实际网格在 CPU 上渲染，与可下载 STL 对应，不依赖 WebGPU，每次旋转 45 度；建议在切片软件中进一步检查。

当前提供翼骨镂空笔筒、飞翼镂空书签、航迹刻度尺和长征火箭书签四种模板。笔筒第一尺寸为外径、第三尺寸为高度，第二尺寸不参与；平面产品依次为长度、宽度和厚度。书签的翼形外廓会使最大宽度超过标称主体宽度，实际包围尺寸在生成结果中显示。附加过孔在主体预设轴线上，直径和轴向位置可调；不是任意表面点选。

批量缩放仅调整第一尺寸；笔筒同时调整高度，其余产品保持宽度、厚度不变。纹样和上传图案目前在固定区域凹刻，尚不支持自由拖拽、凸起模式或自动识别任意照片。输入轮廓需高对比，细线和复杂标志不保证能成功打印。

校园主题均为原创概括：[奋飞园展品中的 AG600 等飞行器](https://nuaa.edu.cn/2022/1031/c852a296745/page.htm)、[明故宫校区太庙井](https://dwjsgzb.nuaa.edu.cn/2020/1222/c14889a276247/page.htm)、[南京航空航天馆圆弧拱顶](https://njhkhtg.nuaa.edu.cn/18237/main.psp)。默认不复制官方校徽；如需使用校徽等学校标识，请查阅[学校视觉识别系统](https://vi.nuaa.edu.cn/)并确认使用条件。

输出是毫米单位的几何模型，不等同于适配特定材料和设备的打印方案。生成后应在切片器检查镂空、细线和支撑；尺子依据几何单位刻线，成品需用可信标准尺核验。
