# 安装与模型管理修复（2026-11-12）

本次修复基于 3.0.1，保留现有桌面界面风格。

- 下载过滤统一为正则表达式，非法规则在联网前报错；检查仓库文件路径，避免写出目标目录。断点下载检查响应范围和每个分片的精确字节数。
- 直连方案的默认 3D 模型、下载文件、配置路径统一为 Hunyuan3D-2mini。TRELLIS.2 与其 GGUF 插件尚未接入对应运行时，目录中显示暂不可用，配置与直连运行均拒绝使用。
- Klein Base 4B 下载预算修正为约 15 GiB，默认采样为 50 步、guidance 4；内存不足的机器不再获得适合安装的标记。资源值仍为估算。
- 安装页支持选择对话模型，显存和系统内存共同限制可选项。安装请求会执行所选 Ollama 模型的拉取，成功后才写入默认模型配置；下载量提示同步更新。
- 更新器读取目标 Release 的实际附件，验证大小、可用的 SHA-256 摘要和包内版本。获取版本失败时明确停止，不再回退旧版本。更新合并保留配置、模型和产物，拒绝越界目标。
- 自动清理仅允许当前安装目录下的模型。外部模型目录可读取和使用，但不自动删除；目录链接和 Windows junction 不视为自有数据。删除失败会报错，运行中的创作进程或安装任务会阻止相冲突的删除。

验证：完整 pytest 233 passed、2 skipped、41 subtests passed；`tools/verify.py --fast` 150/150。另用独立 Edge 浏览器验证安装页选择、安装请求参数和不可用模型禁用状态，无 JavaScript 异常。下载测试实际使用本地 HTTP 服务传输并比较字节，更新器测试模拟 Release 元数据并运行 PowerShell 解析流程。

本次没有重新下载全部大型权重，也没有验证所有模型及量化方式的生成质量。TRELLIS 的禁用表示运行时尚待实现，不表示已经支持自动安装。
