## 一、骨骼线

**模板档**（`human_body.stl`，50k 顶点）：

```
41 s（其中 Blender 37.5 s）→ 21 关节 / skins=1
```

**RigAnything 档**（同一网格）：

```
52 s → 52 关节 / skins=1
```

两档都过 `_validate_glb()` 的二进制校验（真读 GLB 的 skins + joints + JOINTS_0/WEIGHTS_0），
**不信子进程退出码** —— 这条规则今天救了一次：工具退出码 0，但产物命名是 `*_rig.glb`
而校验器只认 `*_rigged.glb`，差点把「没产出」当成功。

### 验证中发现并修掉的 3 个 bug

1. **`--tier riganything` 是假的**：原来只跑模板、然后在 note 里写"需手动跑"。
   实测报 `joints=21`（模板），而 RigAnything 应该给 52。已改成真分派到 `run_riganything.py`。
2. **解释器用错**：RigAnything 依赖 `easydict` / `open3d`，装在 `venv_riganything`，
   用 miniconda 跑 → `ModuleNotFoundError: No module named 'easydict'`。已按 venv 解释器分派。
3. **产物筛选漏掉 `*_rig.glb`**：后端只 glob `*_rigged.glb`，RigAnything 产出 `*_rig.glb` →
   报"没有产出 GLB"。已改为认两种后缀。

## 二、贴图（Paint PBR）

```
1236 s（20.6 min）/ 峰值 10.7 GB / 峰值温度 73°C
产物 verify_paint_00001_.glb 11.6 MB
校验：images=2 textures=2 · baseColorTexture=True · metallicRoughness=True · 有 UV
```

**比研究侧那版慢 5.7 倍**（216 s → 1236 s）：主实例这个节点图带 **remesh + UV 展开 + inpaint**，
研究侧用的是精简图。两个都对，选哪条看要不要接缝修补。

### 让主实例真正能跑的 3 个修复（都是环境层）

| 问题 | 现象 | 修法 |
|---|---|---|
| 缺节点包 | `Hy3D21CameraConfig not found` | 把隔离实例的 `ComfyUI-Hunyuan3D-Paint`（101 MB）装进主实例 |
| 枚举值不符 | `paint_model: 'hunyuan3d-paintpbr-v2-1' not in ['hunyuan3d-paintpbr']` | 工作流值改成 pack 认的 |
| 权重目录是平铺 bin | `no file named model_index.json` | 用 `mklink /J` 指向 3D-Pack 里完整的 diffusers 目录（6.41 GB），原目录改名备份 |
| tokenizer 缺文件 | `vocab and merges must be both from memory or both filenames` | 补 `merges.txt`（同源 CLIP 的，vocab hash 一致） |

## 五、修改（文字引导改参考图）

两次实测，差别很大：

| 指令 | 耗时 | 结果 |
|---|---|---|
| "把机身改成红色涂装，其余保持不变" | 66 s | ❌ 变成红色机器人（主体丢失） |
| "只把机身上加一条红色条纹，飞机外形、发动机、螺旋桨、浮筒全部保持完全一致" | 39 s | ✅ 白色飞机 + 红色条纹，主体保住 |

**结论：这个能力可用，但指令必须把"不许变的部分"逐项写出来。**
qwen21_ref 在 512 分辨率下对"保持不变"的服从度取决于列举的具体程度，
一句话的模糊指令会直接换主体。

## 六、发现的产品缺口（按优先级）

1. **贴图没有产品入口**：现在只能靠研究侧脚本 `run_plane_paint.py`（还要手改 input/output 目录）。
   建议照 `tools/asset_refine_rig.py` 的样子封一个 `tools/paint_asset.py`。
2. **修改能力没有强度旋钮**：`generate_reference` 写死 `resolution_px=512, steps=20`，
   没有 image-to-image 的 denoise 强度参数，所以"改一点点"做不细。
3. **贴图耗时 20 min**：默认带 remesh + inpaint。如果只是要颜色，应该给"快速档"（跳过 remesh）。
4. **精修产物必须自动过小壳过滤**：现在是验证时手动调的，应该固化进 `refine` 返回前。
