## 二、用模型修改产物（256 → 512 提精度）

- 面数 151488 → 400000（×2.64）
- 体积变化 -8.06%
- 表面平均偏移 64.26 mm（p95 195.03 mm，按包围盒归一）
- 512 档把 2 个碎块合成 1 个、并达到面数上限，说明提精度同时解决了碎片问题

## 三、装不起来的（这次实测确认的产品缺口）

| 能力 | 卡在哪 | 根因 |
|---|---|---|
| 出图（5 个图像模型） | 权重全没下载 | 每个 10–30 GB，网络 1–8 MB/s 下不现实 |
| 贴图 PBR | ComfyUI 缺 Paint 节点包 | 节点包在 custom_nodes，本次没装（可装） |
| 3D-Pack 图生 3D | `pytorch3d` 编不出来 | Windows + torch2.6 无预编译轮子，31 处 import 依赖它 |
| 骨骼 / 动画 / 精修 | **产品里缺后端脚本** | `work/research/{rig,precision,motion}` 被排除在仓库外，`tools/asset_refine_rig.py` 直接报「缺研究脚本」 |

**最严重的是最后一条**：技能文档写着「给它绑骨骼 / 精修一下」能用，但干净安装的用户机器上这四个能力的后端脚本根本不在仓库里。

## 四、本次顺手修的安装问题

1. install.ps1：GitHub 直连死等 180s → 镜像优先 + 单源 30s；版本写死 → 自动解析 latest
2. doctor：`${COMFYUI_DIR}` 占位符被报成「目录不存在」→ 识别为未配置
3. 启动：零模型时先卸 Ollama 再启 Strata 白折腾 → `provider_available()` 快速跳过
4. bootstrap：ComfyUI 便携版没进下载队列 / `_extract_archive` 少参数 / 3D-Pack 用 git clone 会 0 字节卡死（改 zip）/ 假成功判断
5. downloader：稀疏预分配导致「没下完也像下完了」→ 去掉 truncate，按实际写入字节校验
6. 2.1 权重：HF 仓库给的是 `.ckpt` 打包（model/vae/conditioner），hy3dgen 要 `.safetensors` 且键要带前缀 → 已转换并跑通
