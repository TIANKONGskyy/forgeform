## 一、一句话

**对着聊天框说一句"做个 XX"，本地出图 → 建模 → 可打印 STL，全程不联网、不上传模型文件。**

## 五、工程数据（可复核）

- 代码：861 个 Python 文件 / 290,272 行；35 份文档；261 次提交
- 测试：31 个测试文件，`pytest` 全绿；`tools/verify.py` 152/152
- 质量闸：3D 产物出厂前查连通块 / 水密 / 面数（不通过自动重试或降级）
- 冷启动到首张图：约 8–10 s（模型已缓存）
- 崩溃恢复：ComfyUI 生成中被关 → 90 s 内报"ComfyUI 断开了"，重启后 18 s 恢复

## 六、已知短板（对外别说满）

1. **贴图/精修/多视图装不起来**：三条都卡在编译型 CUDA 扩展，非代码缺陷
2. **Qwen-Image / FLUX.2 吃 24 GB 显存**：24 GB 卡要选 z_image / SDXL
3. **2.0 模型不保证水密**：打印前要走修补
4. **对话依赖外部 LLM**：没有 LLM 时扩写走规则兜底（能用但不如 7B）
5. **小模型扩写不稳**：Qwen2.5-1.5B 会输出中文、自相矛盾；7B 才稳
