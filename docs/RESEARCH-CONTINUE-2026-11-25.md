## 一、自然步态：已定位根因并修好（可量化）

### 发现的两个硬问题

**① 腿骨比网格长 6.4%**

```
网格底 z = -1.0003
左腿骨链：thigh 0.0543 → toe -1.1288
超出 -0.1284  → 占身高 6.4%
```

腿骨穿出靴底，蒙皮时脚会被拉长 —— 这是"走路像踩高跷"的直接原因。

**② 旧动作几乎没有"支撑期"**

按脚踝高度判定触地帧（z < 最低点 + 0.004）：

| | 支撑帧数 | 支撑期步速抖动 σ |
|---|---|---|
| 旧 FK（Codex 版） | **3–5 帧** | 0.026 |
| 新 IK（本次） | **11–12 帧** | **0.001** |

正常人走路支撑期应占一个步态周期的 **60%** 左右。旧版只有 3–5 帧（30 帧周期的 10–17%）
—— 等于脚刚落地就抬起来，视觉上就是"滑步"。

### 修法

1. **腿链缩放 0.8914×**，把 toe 骨精确落到网格底面（-1.0003）。
2. **脚踝 IK + 空物体目标**：支撑期目标 Y 匀速后移、Z 钉死；摆动期走正弦弧线。
   腿的 FK 关键帧保留（被 IK 覆盖，`influence` 可切回对比）。
3. **髋部起伏**加在根骨：`0.010·cos(4πt)`（每步一次，幅度 1% 身高）。
4. 周期 30 帧，支撑 62% / 摆动 38%，曲线加 CYCLES 修饰器循环。

## 二、彩色贴图：拿到了，但有明显溢出缺陷

`角色_PBR贴图.glb`（3.33 MB）实际是有贴图的：

```
顶点 63,493   UV: TEXCOORD_0 ✔
baseColorTexture ✔   metallicRoughnessTexture ✔
两张 PNG 内嵌（base64）
```

**问题**：渲染出来小腿、靴子上有**青绿色块**（见步态对比图的旧版）。

判断是**贴图溢出（texture bleeding）**：投射生成贴图时，UV 岛外侧的底色（场景背景/邻近区域）
渗进了岛内边缘。腿部是薄筒状、UV 岛密集，最容易中招。

**修法（下一步）**：
1. 生成 UV 岛掩膜 → 只对岛内有效纹素做 **atlas dilation（padding 扩边）**，把岛边缘向外扩 8–16 px；
2. 或重烤：给 3D 模型做 **ID 掩膜 + 多视角投影烘焙**（Blender bake，Cycles），跳过生成式贴图；
3. 校验指标：同一材质区域内色相方差（现在青绿色块会让腿部方差爆掉）。
